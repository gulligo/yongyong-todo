      웹앱은 스스로 잠금 해제를 감지할 수 없어서, 삼성 모드 및 루틴으로 설정합니다.
      1. 크롬 메뉴(⋮) → 홈 화면에 추가 → 설치로 이 앱을 먼저 설치
      2. 갤럭시 스토어에서 Good Lock 설치 → 안에서 루틴+ 설치
      3. 설정 → 모드 및 루틴 → 루틴 → +
      4. 조건(만약): 잠금 해제 시 선택
      5. 동작(실행): 앱 → 앱 열기 → 용용이 할일
